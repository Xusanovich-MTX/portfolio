# TOHIR.DEV — 3D Developer Portfolio Website

Tohir Mamurov (Creative Developer, Python Architect & AI Specialist) shaxsiy 3D interaktiv portfoliyo veb-sayti.

## Texnologiyalar
- **HTML5 & Tailwind CSS** — Zamonaviy dark/neon UI dizayn
- **Three.js (WebGL)** — Interaktiv 3D geometriya va zarralar (particles) animatsiyasi
- **GSAP** — Silliq skroll va interfeys animatsiyalari
- **Interaktiv Simulyatorlar** — HEMIS Telegram Bot, EyePilot Computer Vision va CodeStep jonli demolari
